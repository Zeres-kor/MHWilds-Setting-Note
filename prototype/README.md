# 보유 호석·자동 태그 화면 초안

Windows Edge/Chrome에서 `index.html`을 열거나 프로젝트 루트에서 `python -m http.server 8000 --directory prototype`으로 실행합니다. 외부 서비스와 npm 설치는 필요하지 않습니다.

UI 작업용 `ui-ux-pro-max` 스킬은 `.agents/skills/ui-ux-pro-max/`에 포함돼 있습니다. 앱 실행에는 사용하지 않으며, UI를 수정할 때 해당 `SKILL.md`와 로컬 검색 스크립트를 참조합니다. 출처는 `https://github.com/nextlevelbuilder/ui-ux-pro-max-skill`이고 MIT 라이선스는 스킬 폴더의 `LICENSE`에 있습니다.

화면 디자인은 `docs/UI-DESIGN-GUIDE.md`의 네이버페이 참고 원칙을 따릅니다. 밝은 카드형 현황과 초록색 주요 행동을 사용하며, 원본 이미지나 로고는 포함하지 않습니다.

호석 입력·수정, 표 붙여넣기·기존 TXT 일괄 가져오기, 검색·필터·정렬, 수동 태그 일괄 작업, 삭제, JSON 백업·복원을 지원합니다. 가져오기에는 행별 오류·중복·선택 미리보기가 있으며 오류가 있으면 전체 적용을 막습니다. 중복과 제공된 표에 없는 스킬명은 기본 선택에서 제외하고 사용자가 확인해 추가할 수 있습니다. 상단 태그 기준에서 `.xlsx` 기준 파일을 검증하고 변경 내용을 미리 본 뒤 전체 교체하거나 기준 ID로 병합할 수 있습니다. 기준에 따라 공통과 선택 무기를 각각 평가합니다. 미일치는 미분류이며 비활성 기준은 판정하지 않습니다.

보유 호석과 태그 기준은 브라우저 localStorage의 `mhwilds-app-v2`에 함께 저장됩니다. 기존 `mhwilds-inventory-prototype-v1` 데이터가 있으면 읽어 들이고 첫 변경 시 새 형식으로 저장합니다. 이전 형식의 JSON 백업은 호석만 복원하고 현재 기준은 유지합니다. 새 백업에는 호석과 기준이 모두 포함됩니다. 실데이터를 입력했다면 JSON 백업을 별도로 보관하세요.

일괄 가져오기의 스킬명은 제공된 `inputs/호석테이블.xlsx`의 112개 이름과 비교합니다. TXT는 스킬·레벨 3쌍, 방어구 슬롯 3칸, 무기 슬롯 3칸의 12열이며 파일에 없는 레어도·태그·메모는 채우지 않습니다. 표 붙여넣기는 마지막에 메모 열을 추가할 수 있습니다. 한 번에 최대 500행을 처리합니다. 이 표나 현재 화면 입력 검증은 게임 내 호석 생성 가능 여부를 보증하지 않습니다. 장비 세팅 검색과 Windows 배포는 아직 구현되지 않았습니다.

엑셀 압축 해제에는 함께 포함한 fflate 0.8.2를 사용합니다. 라이선스는 `vendor/fflate-LICENSE`에 있습니다. 단위 테스트는 `node --test tests/*.test.cjs`로 실행합니다.
