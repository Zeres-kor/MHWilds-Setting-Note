# 보유 호석 화면 초안

Windows에서 이 폴더의 index.html을 브라우저로 열 수 있습니다. 외부 라이브러리·네트워크 연결은 필요하지 않습니다. 파일 실행 환경에서 브라우저 저장이 제한되면 저장 오류가 표시됩니다. 호석 입력, 필터, 정렬, 수동 태그 일괄 추가·제거, 삭제, JSON 백업·복원을 체험합니다.

호석 정보는 해당 브라우저 로컬 저장소에 저장됩니다. 이 초안은 최종 백업 형식과 별개입니다. 자동 평가·엑셀 업로드·실제 생성 가능 여부 검증·세팅 검색은 미구현이며 자동 평가 값은 모두 미분류입니다. 평가순 정렬은 판정기 연결 전에는 최근 등록순을 사용합니다. 실데이터를 사용할 경우 JSON 백업을 별도로 보관하세요.

로컬 HTTP 실행: 프로젝트 루트에서 `python -m http.server 8000 --directory prototype` 실행 후 `http://localhost:8000` 접속.
