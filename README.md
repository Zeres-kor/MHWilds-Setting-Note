# MHWilds 세팅노트

몬스터헌터 와일즈의 **보유 호석을 관리하고, 원하는 스킬을 갖춘 장비 세팅을 검색·저장·비교하는 프로그램**입니다. 브라우저에서 바로 사용할 수 있으며, 호석과 저장 세팅은 사용하는 브라우저에 보관됩니다.

이 프로그램은 **AI 코딩 도구(Codex)를 활용해 제작**했습니다. 기능 요구사항과 디자인 방향을 정하고 AI로 구현·수정을 진행했으며, 검색 로직·데이터·화면을 테스트하며 개선하고 있습니다. 현재 검증 범위와 계산 제한은 아래에 명시합니다.

**[MHWilds 세팅노트 실행하기](https://zeres-kor.github.io/MHWilds-Setting-Note/)**

## 주요 기능

| 메뉴 | 할 수 있는 일 |
| --- | --- |
| 보유 호석 | 호석 등록·수정·삭제, 게임 추출 파일 일괄 가져오기, 스킬·슬롯·태그 필터와 정렬 |
| 태그 기준 | 엑셀 평가 기준 가져오기, 변경 미리보기, 범용·무기별 자동 평가 |
| 호석 후보 검색 | 커뮤니티 생성 규칙에 따른 후보 검색과 보유 수량 확인 |
| 세팅 검색 | 고정 무기·목표 스킬·방어력·내성 조건에 맞는 방어구·호석·장식주 조합 검색 |
| 저장 세팅 | 검색 결과 저장, 이름·메모 편집, 최대 3개 세팅 비교 |

## 보유 호석 가져오기

1. **보유 호석 → 일괄 가져오기**를 엽니다.
2. 게임에서 추출한 `Exported_Talismans.txt`를 선택하거나 업로드 영역에 끌어놓습니다.
3. 스킬·레벨·슬롯과 중복 여부를 검토한 뒤 선택한 행을 저장합니다.

게임 추출 TXT는 **[Nexus Mods #3087](https://www.nexusmods.com/monsterhunterwilds/mods/3087)**을 사용해 추출한 사용자 제공 `Exported_Talismans.txt`를 기준으로 가져오기를 확인했습니다. **다른 모드에서 추출한 파일은 호환 여부 확인이 필요합니다.** 해당 모드의 모든 버전이나 출력 형식을 검증했다는 뜻은 아닙니다.

쉼표·탭으로 구분한 호석 표 붙여넣기도 지원합니다. 중복 구성은 기본 선택에서 제외되지만 같은 호석을 여러 개 보유했다면 직접 선택할 수 있습니다. 알 수 없는 스킬은 확인 필요로 표시하며, 오류 행은 수정한 후 저장합니다.

자동 평가와 직접 입력한 수동 태그·메모는 따로 관리합니다. 보유 호석 표는 표 영역 안에서 스크롤하며 제목 행이 고정됩니다.

## 태그 기준과 자동 평가

**태그 기준**에서 [빈 엑셀 양식](templates/태그기준_빈양식.xlsx)에 맞춘 파일을 가져옵니다. 적용 전 기준 변경과 호석 평가 변동을 미리 확인할 수 있습니다.

평가는 **극종결 → 종결 → 준종결 → 상급 → 일반** 순서이며, 범용과 무기별 평가를 각각 표시합니다. 극종결·종결은 기준 스킬·슬롯의 정확 일치, 준종결 이하는 기준 이상 충족을 사용합니다. 평가 기준을 바꾸어도 수동 태그와 메모는 유지됩니다.

## 장비 세팅 검색

1. **세팅 검색**에서 무기 종류와 고정 무기를 선택합니다.
2. 호석 범위를 **전체 규칙 호석 / 보유 호석만 / 호석 사용 안 함** 중에서 선택합니다.
3. 분류별 스킬 목록에서 목표 레벨·효과를 선택합니다. 목표 개수에 임의 제한은 없습니다.
4. 필요하면 최소 방어력과 불·물·번개·얼음·용의 최소 내성을 지정합니다.
5. **세팅 검색**을 눌러 장비 조합과 장식주 배치를 확인합니다.

- 무기는 **아티어와 제작 최종 강화 단계**만 표시하며 거극 아티어를 먼저 배치합니다.
- 제작 무기의 모든 기본 스킬은 목표에 자동 반영됩니다. 제작 무기 전용 스킬은 수동 목록에서 제외하고 선택 요약에 표시합니다.
- 거극 아티어는 고정 무기 옆에서 실제 무기의 시리즈·그룹 스킬을 각각 지정할 수 있습니다. 각각 1부위로 합산합니다.
- 방어구는 **상위만 검색**하며, 방어력은 최대 강화 기준입니다.
- 최소 내성은 **제한 없음 또는 -25~+25** 드롭다운으로 선택합니다. 방어구 다섯 부위의 기본 내성 합계이며 스킬·식사 효과는 포함하지 않습니다.

검색은 최대 **20개 대표 결과**, **20초**, **200,000회 탐색**에서 중단합니다. 제한에 도달하면 부분 결과로 표시하며, 부분 검색의 결과가 0개라고 해서 가능한 세팅이 없다는 뜻은 아닙니다.

## 세팅 저장과 비교

검색 결과의 **이 세팅 저장**을 누르면 **저장 세팅**에 보관됩니다. 이름과 메모를 편집하고 최대 3개를 선택해 무기·방어구·호석·장식주·스킬·방어력·기본 내성을 비교할 수 있습니다. 최대 200개를 저장합니다.

저장 세팅은 검색 당시의 독립 스냅샷입니다. 이후 보유 호석이나 평가 기준을 수정해도 저장한 조합은 바뀌지 않습니다.

## 데이터 보관과 백업

호석·평가 기준·저장 세팅은 **현재 브라우저의 localStorage**에 저장됩니다. 가져온 파일은 브라우저에서 읽으며 서버로 업로드하지 않습니다.

**백업 저장**으로 JSON 파일을 내려받고, **백업 복원**으로 데이터를 옮길 수 있습니다. 브라우저 데이터를 삭제하거나 다른 브라우저·기기로 옮기기 전에 백업을 저장하세요. 복원은 전체 데이터를 교체하므로 적용 전 내용을 확인하세요.

## 데이터 출처와 계산 범위

장비 데이터는 [MHDB 한국어 API](https://wilds.mhdb.io/ko/armor), 스킬 분류와 표시 순서는 [와일즈 시뮬레이터](https://mhwilds.wiki-db.com/sim/) 및 사용자 참고 화면을 기준으로 구성했습니다. 호석 후보는 프로젝트에 포함된 원본 표와 출처가 기록된 커뮤니티 보완 규칙을 사용합니다.

장비 스냅샷의 API 반영 버전은 **2026-04-15T01:28:18+00:00**입니다. Capcom 게임 버전 번호가 아니며 최신 게임과의 일치는 별도 확인이 필요합니다.

현재 공격력 최적화, 아티어 복원 수치, 보유 장식주 수량 제한, 장비 제작 가능 여부는 계산하지 않습니다. 모든 외형·장비 조합을 나열하는 방식이 아닌 목표 조건에 대한 대표 조합 검색입니다. 거극 부여 스킬 입력은 실제 무기의 효과를 지정하는 기능이며 무작위 부여 가능성을 검증하지 않습니다.

자세한 근거와 범위는 [장비 검색](docs/BUILD-SEARCH.md), [호석 후보 검색](docs/CANDIDATE-SEARCH.md), [호석 규칙 검토](docs/TALISMAN-RULE-AUDIT.md), [저장·백업 호환](docs/SAVED-BUILDS.md)을 참고하세요.

## 피드백·오류 제보

화면 상단의 **피드백·오류 제보** 링크 또는 [GitHub Issues](https://github.com/Zeres-kor/MHWilds-Setting-Note/issues)에서 의견을 남길 수 있습니다. 이슈 작성에는 GitHub 로그인이 필요합니다.

검색 오류는 무기·호석 범위·목표 스킬·방어력/내성 조건, 예상 결과와 실제 결과, 사용 브라우저를 함께 알려주세요. 데이터 오류는 장비명과 게임 화면 또는 출처가 있으면 확인에 도움이 됩니다. 전체 개인 백업 대신 오류를 재현하는 데 필요한 정보만 공유해 주세요.

## 개발과 배포

화면은 `prototype/`의 HTML·CSS·JavaScript로 구성됩니다. `main`의 화면·테스트·배포 설정 변경은 GitHub Actions 검증 후 GitHub Pages에 자동 배포됩니다.

```sh
node --test tests/*.test.cjs
node --check prototype/app.js
```

변경한 JavaScript 모듈도 구문 검사를 수행합니다. 엑셀 양식·호석 규칙을 재생성할 때는 Python과 `openpyxl`이 필요합니다. 상세 개발 맥락은 [HANDOFF.md](HANDOFF.md), 배포 설정은 [GitHub Pages 안내](docs/GITHUB-PAGES.md)에 있습니다.
