# 와일즈 호석 관리·세팅 검색

Windows PC에서 로컬로 사용하는 프로그램을 만드는 프로젝트입니다. 현재는 보유 호석 관리, 엑셀 기준 자동 평가와 호석 후보 검색을 사용할 수 있습니다. 완성된 세팅 시뮬레이터는 아닙니다.

## Windows에서 이어가기
1. GitHub 저장소를 클론하거나 전달받은 ZIP을 `C:\Projects` 등 원하는 위치에 압축 해제합니다. 숨김 폴더 `.agents`도 유지하세요.
2. 로컬 Codex에서 해당 프로젝트 폴더를 엽니다.
3. 아래 내용을 새 대화에 붙여넣습니다.

> HANDOFF.md와 AGENTS.md를 읽고 이 프로젝트를 이어서 진행해줘. 지금까지 합의된 요구사항을 유지하고, 먼저 보유 호석 화면 초안을 실제 브라우저에서 검증한 다음 남은 구현을 진행해줘.

## 화면 초안 실행
GitHub Pages 자동 배포 설정을 포함합니다. 최초 활성화 방법과 접속 주소는 [Pages 안내](docs/GITHUB-PAGES.md)를 참고하세요. 활성화 후에는 `main`의 화면 변경이 테스트를 통과하면 자동 배포됩니다.

`prototype/index.html`을 Edge 또는 Chrome으로 엽니다. 외부 서비스나 npm 설치는 필요하지 않습니다. 엑셀 읽기에 필요한 fflate 0.8.2와 라이선스가 `prototype/vendor/`에 포함돼 있습니다. 호석 후보 검색은 HTTP(S) 실행이 필요합니다. GitHub Pages 또는 아래 로컬 HTTP 실행을 사용하세요. 파일 실행에서 브라우저 저장이 제한되는 경우에도 HTTP 실행을 사용하세요.

Python이 설치된 PC에서는 프로젝트 폴더에서 다음을 실행할 수 있습니다.

```powershell
python -m http.server 8000 --bind 127.0.0.1 --directory prototype
```

브라우저에서 `http://localhost:8000`을 엽니다. 종료는 터미널에서 Ctrl+C입니다. 파일 실행과 HTTP 실행의 저장소는 서로 다를 수 있으므로 이동 전에 JSON 백업을 저장하세요.

## 자동 태그 기준
상단의 태그 기준에서 `templates/태그기준_빈양식.xlsx` 형식의 파일을 업로드합니다. 추가·변경·삭제 및 보유 호석 태그 변동 수를 미리 본 다음 적용합니다. 전체 교체와 기준 ID 병합을 선택할 수 있습니다. 작성 예시는 모든 행이 비활성입니다.

공통과 선택 무기의 자동 평가를 따로 표시하고 필터·정렬에 반영합니다. 평가 기준은 브라우저에 보유 호석과 함께 저장되며 새 JSON 백업에도 포함됩니다. 기존 화면 초안의 JSON 백업은 호석만 복원하고 현재 태그 기준은 유지합니다. 기준 스킬명은 원본 호석 표에 게임 추출 표기와 누락된 가드 강화를 반영한 113개 목록으로 확인합니다. 실제 게임에서 해당 호석이 생성 가능한지는 아직 판정하지 않습니다.

## 보유 호석 일괄 가져오기
`일괄 가져오기`에서 게임에서 추출한 `Exported_Talismans.txt` 또는 기존 호석 `.txt` 파일을 선택하거나 업로드 영역에 끌어놓습니다. 파일을 읽으면 행 검토 결과를 자동으로 표시합니다. 엑셀 표 붙여넣기도 지원합니다. 스킬·레벨 3쌍, 방어구 슬롯 3칸, 무기 슬롯 3칸 순서의 12열입니다. 표 붙여넣기는 마지막에 메모를 더한 13열도 지원하며 쉼표나 탭으로 구분할 수 있습니다.

저장 전에 각 행의 스킬명·레벨·슬롯을 확인하고, 기존 목록이나 같은 입력에 있는 동일 구성을 표시합니다. 중복 행은 기본 선택에서 제외하지만 여러 개를 보유했다면 직접 선택할 수 있습니다. 제공된 스킬 표에 없는 이름은 확인 필요로 표시하고 기본 선택에서 제외합니다. 오류 행이 있으면 저장을 막고 행 번호와 이유를 표시합니다. 한 번에 5,000행까지 처리합니다. TXT에는 없는 레어도·태그·메모를 임의로 만들지 않습니다.

TXT와 태그 기준 엑셀은 각각의 업로드 영역에, JSON 백업은 `백업 복원` 버튼 위에 끌어놓을 수 있습니다. 한 번에 파일 하나만 처리하며 TXT·엑셀은 2MB, JSON 백업은 10MB까지 지원합니다. 중복을 포함한 전체 수량을 추가하려면 검토 결과의 `오류 없는 행 모두 선택`을 사용하세요. 알 수 없는 스킬도 이 선택에 포함되므로 상태를 확인하세요.

검증: `node --test tests/*.test.cjs`. 앱 JavaScript 구문 확인: `node --check prototype/app.js`.

## 엑셀 기준 호석 후보 검색
메뉴의 `호석 후보 검색`에서 스킬·최소 레벨·레어도·최소 슬롯·평가 조건을 입력합니다. 조건에 맞는 엑셀 후보, 공통/무기별 태그와 보유 수량을 표시합니다. 검색 취소를 지원하며 최대 200개를 표시하고 20,000개를 넘으면 부분 검색으로 안내합니다. 후보는 보유 호석에 자동 등록되지 않습니다.

원본 표에는 가드 강화가 빠져 있습니다. 게임 추출 555개 중 536개만 표로 설명됐으며 동일 스킬 중복 규칙도 미확정입니다. 이 검색을 실제 게임 전체 후보나 장비 세팅 계산으로 해석하지 마세요. 상세 범위와 검증은 [후보 검색 안내](docs/CANDIDATE-SEARCH.md)를 참고하세요.

## 파일 구성
- `HANDOFF.md`: 합의 사항, 작업 상태, 검증 상태, 다음 작업
- `docs/`: PRD, 기능명세, 사용자 흐름, 화면 초안, 태그 규칙
- `prototype/`: HTML/CSS/JS 화면 초안
- `templates/`: 태그 기준 빈 엑셀·비활성 작성 예시
- `inputs/`: 사용자 첨부 원본과 게시물 캡처
- `.agents/skills/`: 프로젝트용 agent-skills 25개
- `.agents/references/`: 스킬 공통 참고 문서
- `scripts/create_tag_templates.py`: 엑셀 양식 재생성 스크립트

엑셀 양식 또는 `scripts/export_talisman_recipes.py`로 검색 규칙 JSON을 재생성할 때만 Python 패키지 `openpyxl`이 필요합니다. 기존 엑셀을 사용하거나 화면 초안을 여는 데는 설치할 필요가 없습니다.

Git 저장소는 이미 초기화돼 있습니다. 보유 호석 등 개인 백업은 기본적으로 Git에 포함하지 않습니다.
