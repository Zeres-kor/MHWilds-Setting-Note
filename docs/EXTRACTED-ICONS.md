# 사용자 추출 아이콘 적용

- 장식주 361개: 앱의 순차 ID와 추출 데이터의 해시 ID가 달라 이름·종류·필요 슬롯 레벨로 대조. 361개 모두 일치.
- 슬롯별 조합 583개: 장식주 본체의 레벨을 유지하면서 장착 슬롯 크기에 대응하는 이미지 사용.
- 무기 14종·방어구 5종: 기록된 RARE 1~12 이미지 사용. 미기록은 기본 이미지. 호석은 제공된 기본 이미지 사용.
- 검색 결과·저장 세팅 상세 및 공통 요약 아이콘에 적용. 데이터·저장 형식은 유지.
- 빈 슬롯, 속성·방어 스테이터스 및 미대응 심볼은 기존 SVG 유지.
- 스킬 심볼 14개는 assets/game-icons/skills에 보관. 제공 묶음에도 이름별 대응이 미확정이므로 임의 연결하지 않음. 기존 스킬 아이콘 유지.
- 제공 이미지의 삼각형 최종 배치·명암은 게임 화면과 픽셀 대조되지 않은 시안이라는 원본 설명 유지(SOURCE.md).

검증: 기존 Node 테스트 92개 통과, 슬롯 조합 이미지 583개 파일 경로 확인, Chromium에서 장비·장식주 이미지 26개 로드 확인. 전체 화면별 상호작용 재검증 및 공개 배포는 수행하지 않음.
