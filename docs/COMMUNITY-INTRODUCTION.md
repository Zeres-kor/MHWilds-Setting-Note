# 몬스터 헌터 채널 소개글 초안

게시 전 [전체 공지](https://arca.live/b/monsterhunters/160006694)와 [호출벨](https://arca.live/b/monsterhunters/182589443)을 확인한다. 공지의 홍보 사전 문의 및 존댓말 금지에 맞춰 호출벨에서 게시 가능 여부와 글머리를 확인한 뒤 사용한다. 아래는 게시용 반말 초안이며 실제 게시하거나 운영진 허가를 받았다는 뜻은 아니다.

## 제목

와일즈 호석 관리·세팅 검색 도구 만들어봄 — MHWilds 세팅노트

## 본문

보유 호석 정리하고 그 호석으로 원하는 스킬 세팅 찾으려고 **MHWilds 세팅노트**를 만들고 있음.

**AI 코딩 도구인 Codex를 활용해서 제작했음.** 원하는 기능과 디자인을 정하고 AI로 구현·수정하는 방식으로 작업했고, 테스트랑 실제 브라우저 확인을 하면서 개선 중임. 아직 데이터나 검색 오류가 있을 수 있어서 써보고 이상한 점 알려주면 좋겠음.

사용 링크: https://zeres-kor.github.io/MHWilds-Setting-Note/

별도 설치 없이 브라우저에서 쓸 수 있음.

### 지금 되는 기능

- 보유 호석 입력·수정 / 게임 추출 TXT 일괄 가져오기
- 스킬·슬롯·태그 필터와 정렬, 직접 정한 기준으로 범용·무기별 평가
- 전체 규칙 호석 / 보유 호석만 / 호석 없이 세팅 검색
- 제작 최종 단계 무기와 아티어 선택, 제작 무기 기본 스킬 자동 반영
- 거극 아티어 시리즈·그룹 스킬 입력
- 목표 스킬·최소 방어력·속성 내성 조건 지정
- 세팅 저장 / 최대 3개 비교 / JSON 백업·복원

### 호석 TXT 가져오기

보유 호석 → 일괄 가져오기에서 파일을 선택하거나 끌어놓으면 됨. 저장 전에 스킬·슬롯·중복 여부를 확인할 수 있음.

TXT는 아래 모드를 사용한 사용자 제공 `Exported_Talismans.txt`로 확인했음.

https://www.nexusmods.com/monsterhunterwilds/mods/3087

다른 모드의 TXT는 호환 여부 확인이 필요함. 위 모드도 모든 버전과 출력 형식을 검증한 건 아님.

### 사용 전에 알아둘 점

- 최신 게임 데이터와 완전히 일치하는지 검증한 상태는 아님.
- 공격력 최적화, 아티어 복원 수치, 보유 장식주 수량 제한은 미지원임.
- 상위 방어구만 검색함. 내성은 방어구 기본 합계라 스킬·식사 효과는 제외함.
- 최대 20개 대표 결과를 보여주며 시간·탐색 제한이 있음. 부분 검색에서 결과가 없다고 불가능한 세팅으로 확정하면 안 됨.
- 종결 같은 평가는 지정한 기준에 따른 표시임. 실제 획득 확률을 계산하는 기능은 아님.

호석과 저장 세팅은 사용하는 브라우저에 저장됨. 가져온 파일은 서버로 업로드하지 않음. 브라우저 데이터를 지우거나 다른 기기로 옮기기 전에는 백업 저장으로 JSON을 받아두면 됨.

### 피드백

잘못된 장비·스킬 정보, 검색 결과 오류, TXT 가져오기 문제, 불편한 메뉴나 추가하면 좋을 기능 알려주면 좋겠음.

댓글로 남겨도 되고, 화면 상단 **피드백·오류 제보**에서 GitHub Issues로 남겨도 됨. 이슈 작성은 GitHub 로그인이 필요함.

https://github.com/Zeres-kor/MHWilds-Setting-Note/issues
