# 호석 보관함 UI·UX 기준

참고: [WWIT 네이버페이 화면 모음](https://wwit.design/2025/02/15/npay/)의 자산 홈·목록, 결제 필터, 혜택 탭, 메뉴 화면. 이 글은 화면 스크린샷 모음이므로 아래 내용은 실제 화면에서 관찰한 패턴이다. 네이버페이의 로고·이미지·문구는 사용하지 않는다.

## 앞으로 적용할 원칙

1. 연한 회색 배경에 흰색 카드로 영역을 나눈다. 제목·숫자·설명 순서로 정보를 읽을 수 있게 한다.
2. 핵심 행동 하나에 선명한 초록색을 사용한다. 보조 행동은 흰색 버튼으로 구분하고, 평가나 오류를 색상만으로 전달하지 않는다.
3. 목록과 필터의 제목을 짧고 명확하게 쓴다. 선택 결과와 전체 수를 가까이 보여준다. 좁은 폭의 표는 스크롤 안내를 제공한다.
4. 둥근 모서리, 얇은 구분선, 일정한 간격으로 카드·버튼·입력칸을 통일한다. 화면을 채우기 위한 홍보 배너나 장식은 추가하지 않는다.
5. 한국어 본문은 16px을 기준으로 읽기 쉽게 유지한다. 키보드 초점, 명도 대비, 터치 영역, 320px부터의 가로 넘침을 확인한다.
6. 스타일 변경 때 보유 호석 입력·일괄 가져오기·태그 기준·필터·백업 기능이 계속 동작하는지 브라우저에서 확인한다.

현재 화면은 이 원칙을 적용해 밝은 카드형 현황, 초록색 입력 버튼, 필터 카드, 목록과 대화상자 스타일을 사용한다. 모바일 앱의 결제 흐름이나 자산 금액 구조를 호석 앱에 그대로 옮기지 않는다.
