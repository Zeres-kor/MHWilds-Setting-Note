# 호석 보관함 UI·UX 기준

## 디자인 방향

2026-10-05 사용자 요청으로 기존 네이버페이 참고 방향을 몬스터헌터 와일즈 공식 사이트 참고 방향으로 대체한다. 앞으로 보유 호석 화면과 세팅 검색 등 새 화면에도 같은 기준을 적용한다.

## 확인 및 적용 상태

현재 구현은 이전의 밝은 카드·초록색 주요 버튼 스타일이다. 새 방향의 화면 구현은 아직 진행하지 않았다. 공식 사이트는 클라우드 네트워크 제한으로 접속하지 못했으며, `www.monsterhunter.com` 허용 설정 초안을 저장했다. 설정 반영 후 세 페이지의 실제 화면을 확인해야 한다.

실제 페이지의 색상, 서체 계층, 배경, 테두리, 버튼, 내비게이션과 모바일 구성을 관찰하고, 공통 패턴을 이 문서에 기록한 뒤 구현한다. 확인하지 않은 시각적 특성을 공식 사이트의 특징이라고 단정하지 않는다.

## 유지할 사용성 원칙

1. 공식 사이트의 시각적 분위기를 호석 관리·세팅 검색에 맞게 적용한다. 홍보용 대형 영상이나 배너보다 검색·목록·입력의 접근성을 우선한다.
2. 원본 로고·이미지·문구를 복제하지 않는다. 장식은 앱에 맞게 직접 구성한다.
3. 핵심 행동과 보조 행동을 구분하고 평가·오류·선택 상태를 색상만으로 전달하지 않는다.
4. 한국어 본문은 16px을 기준으로 유지한다. 본문 대비 4.5:1, 키보드 초점, 충분한 터치 영역과 동작 감소 설정을 확인한다.
5. 320px부터 데스크톱까지 반응형을 확인한다. 넓은 표는 표 영역 안에서 스크롤하고 안내를 제공한다.
6. 스타일 변경 후 입력·일괄 가져오기·드래그앤드롭·태그 기준·필터·백업 기능을 브라우저에서 검증한다.
