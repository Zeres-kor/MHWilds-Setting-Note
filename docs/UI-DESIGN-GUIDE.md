# 호석 보관함 UI·UX 기준

## 디자인 방향과 근거

2026-10-05 사용자 요청으로 기존 네이버페이 방향을 몬스터헌터 와일즈 공식 디자인 참고 방향으로 대체했다. 이후 제공된 `Monster Hunter Wilds 공식 웹 매뉴얼.html`의 내장 CSS와 메뉴 구조를 확인하고 보유 호석 화면에 적용했다. 첨부 문서의 내용은 디자인 참고 자료로 취급한다.

주요 구현 근거는 [공식 웹 매뉴얼](https://manual.capcom.com/mhwilds/ko/steam/top)이다. 추가 참고 후보는 [공식 메인](https://www.monsterhunter.com/wilds/ko-kr/), [DLC](https://www.monsterhunter.com/wilds/ko-kr/product/dlc/), [미디어](https://www.monsterhunter.com/wilds/ko-kr/media/)이며 이 세 페이지는 사이트 측 403 때문에 실제 화면을 확인하지 못했다.

매뉴얼 HTML에는 스타일이 내장돼 있으나 이미지와 번들 JS는 별도 폴더를 참조한다. 해당 폴더는 첨부되지 않았으므로 완전한 원본 화면을 재현했다고 주장하지 않는다. 원본 스크립트는 실행하지 않았다.

## 확인한 패턴

- 검은 기본 배경과 흰 본문: 원본 `html,body`의 `background:#000`, `color:#fff`.
- 올리브색 사이드 메뉴: `.sidebar`의 `rgba(80,79,49,.9)` 및 어두운 메뉴 행.
- 금색·황토색 프레임과 강조: `#846b39`, `#564e34`, `#ffda5b`, `#f89f32`.
- 명조 계열 서체: Times New Roman, Yu Mincho 등 serif 폰트 스택.
- 데스크톱의 왼쪽 카테고리 메뉴와 본문 영역, 좁은 화면의 별도 레이아웃.
- 이미지로 구성된 제목 장식과 프레임. 앱에서는 로컬 CSS 선과 모서리 장식으로 해석한다.

## 앞으로 적용할 원칙

1. 어두운 배경, 올리브색 내비게이션, 금색 강조와 절제된 프레임을 공통 시각 언어로 사용한다. 보유 관리·세팅 검색·저장 세팅에도 일관되게 적용한다.
2. 제목은 한국어 명조 계열, 본문·폼·표는 읽기 쉬운 고딕 계열로 구분한다. 원본의 서체 분위기를 살리면서 한국어 데이터의 가독성을 확보한다.
3. 주요 행동에는 금색 배경과 어두운 글씨를 사용하고, 보조 행동은 어두운 면과 테두리로 구분한다. 평가·오류·선택 상태는 텍스트로도 전달한다.
4. 홍보용 대형 영상보다 검색·목록·입력의 접근성을 우선한다. 사용자가 직접 제공하고 적용을 요청한 로고·월페이퍼는 로컬 자산으로 사용할 수 있다. 그 외 장식은 CSS 및 자체 SVG를 사용한다. 원격 폰트나 이미지에 의존하지 않는다.
5. 본문 16px, 일반 텍스트 대비 4.5:1, 명확한 키보드 초점, 충분한 터치 영역과 동작 감소 설정을 유지한다.
6. 데스크톱은 왼쪽 메뉴로 구분하고 좁은 화면은 가로 메뉴와 두 열 필터를 사용한다. 넓은 표는 표 영역 안에서 스크롤하며 안내를 제공한다.
7. 스타일 변경 후 입력·가져오기·드래그앤드롭·태그 기준·필터·백업을 브라우저에서 검증한다. 실제 보유 데이터는 화면 미리보기나 저장소에 포함하지 않는다.

## 현재 적용과 검증

`prototype/style.css`와 `prototype/index.html`에 테마와 자체 호석 마크를 적용했다. 320·768·1440px 브라우저에서 문서 가로 넘침, 가져오기·저장·새로고침 후 유지, 입력 및 태그 기준 대화상자를 확인했다. 최신 화면은 `docs/previews/`에 기록한다. 원본의 게임 이미지가 없는 조건에서 CSS에 근거한 디자인 해석이며 원본 화면 복제는 아니다.

## 사용자 제공 로고·월페이퍼 적용

2026-10-07 사용자가 제공한 ZIP의 STDB-Logo.png(640×360 투명 PNG)와 STDB-Wallpaper.png(1438×810)를 원본 그대로 prototype/assets에 포함했다. 로고는 상단 브랜드 링크에 비율을 유지해 표시하고 접근 가능한 이름을 제공한다. 월페이퍼는 전체 배경에 어두운 레이어를 겹치며 입력·목록·제목 패널은 읽기 쉬운 어두운 면을 유지한다. 모바일은 로고를 줄이고 배경을 스크롤 방식으로 표시한다. 외부 이미지 요청 없이 로컬/Pages에서 동작한다. 이 적용은 사용자의 명시적 이미지 사용 요청에 따른 기존 자산 원칙의 예외다. 원본 저작권은 해당 권리자에게 있으며 프로젝트 코드 라이선스에 포함된다는 뜻은 아니다.

## 검색 결과 상세 — 인게임 장비 화면 참고 (2026-10-08)

사용자가 제공한 합성/원본 게임 화면을 상세 카드의 직접 참고로 사용한다. 장비와 장식주 부위별 정렬, 검은 반투명 패널, 가는 금색 경계, 스킬 레벨 칸, 시리즈·그룹 기여 장비, 오른쪽 방어 스테이터스 구조를 따른다. 호석 패널은 별도로 구분하고 캐릭터 영역은 만들지 않는다. 아이콘은 참고 화면의 실루엣을 바탕으로 자체 SVG로 구현하며 원본 텍스처 사용으로 표현하지 않는다. 텍스트와 숫자를 함께 표시해 색상만으로 상태를 전달하지 않는다.
