## 태그 기준 엑셀 제안
한 행은 한 규칙. 열: 기준 ID, 적용 무기(공통 또는 무기 종류), 태그명, 스킬1~3 및 레벨, 무기 슬롯, 방어구 슬롯, 일치 방식, 우선순위, 설명. 정확 열 이름과 슬롯 기입 형식은 샘플 파일로 확정한다.

상세 양식과 판정 정의는 [TAG-RULES.md](TAG-RULES.md)에 정리했다. 엑셀 초안은 `templates/태그기준_빈양식.xlsx`, 비활성 작성 예시는 `templates/태그기준_작성예시.xlsx`다. 스킬판정과 슬롯판정을 각각 지정하며 기본 정책은 종결=정확 일치, 준종결 이하=기준 이상이다. 같은 범위에서는 최우선 태그 하나를 표시한다.

## 판정 원칙과 미확정 부분
- 스킬 입력 순서에 영향받지 않는다. 동일 스킬 중복의 정규화는 게임 규칙 확인 후 결정한다.
- 공통과 무기별 판정은 독립적으로 유지한다.
- 종결은 정확 일치, 준종결 이하 등급은 조건 이상 충족을 기본으로 한다. 슬롯 이상 충족은 슬롯 합계가 아니라 종류별 개수·크기를 비교한다.
- 같은 범위에서 여러 규칙이 맞으면 최우선 태그 하나를 표시한다. 공통·무기 태그는 독립적이다. 다른 태그의 같은 범위·동순위 활성 기준은 업로드 오류로 처리한다.
- 수동 태그는 자동 재분류가 덮어쓰지 않는다.
- 스킬 ID와 사용자 태그명을 구분하며 스킬명을 바꿔 게임 데이터를 수정하지 않는다.

## 구현된 검색 준비 단계

엑셀 기준 호석 후보 검색을 구현했다. SRCH-01의 장비·장식주 세팅 계산은 아직 미구현이다. 현재 검색 범위·조건·취소·부분 결과 정책과 검증은 [CANDIDATE-SEARCH.md](CANDIDATE-SEARCH.md)를 따른다.
