# 텍스트 와이어프레임

공통: 창 너비에 맞는 유동 레이아웃. 모든 화면 상단에 메뉴와 현재 데이터 버전·상태. 고정 최대 폭으로 넓은 PC 화면을 낭비하지 않는다. 필터·정렬·선택 작업은 목록 가까이에 둔다.

## 보유 호석
```text
[보유 호석] [태그 기준] [세팅 검색] [저장 세팅] [데이터·백업]
보유 호석                              [빠른 입력] [일괄 입력] [가져오기]
무기 | 범용 태그 | 무기 태그 | 스킬·레벨 조건 | 슬롯 조건 | 정렬
적용 조건 칩                                         [초기화]
선택 n개                                  [수동 태그 변경] [삭제]
선택 | 스킬 구성 | 슬롯 종류·크기 | 범용 태그 | 무기 태그 | 메모
호석 목록 (창 너비에 맞춰 확장)
선택 시 상세: 전체 무기 태그 / 판정 기준 / 메모 / 수정
```
입력: 자동완성과 키보드 이동, 저장 후 연속 등록. 빈 상태: 등록·가져오기 버튼. 로딩: 읽기/재분류 상태. 오류: 해당 입력 또는 가져오기 행과 함께 설명.

## 태그 기준
```text
태그 기준                 [엑셀 양식 받기] [기준 파일 업로드]
범위: [공통] [무기 선택]                       현재 기준 버전
기준 ID | 태그 | 스킬 | 슬롯 | 일치 방식 | 우선순위 | 설명
업로드 후: 오류 행·열 / 추가·변경·삭제 / 분류 변경 요약
                                             [취소] [적용]
```
빈 상태: 양식과 업로드 안내. 로딩: 검증·재분류 상태. 오류: 기존 기준이 유지됐음을 표시. 양식 다운로드는 업로드 형식 확정 후 구현한다.

## 세팅 검색
```text
무기 | [전체 가능 호석 / 보유 호석]
목표 스킬·레벨 / 장비 조건 / 슬롯·세트 관련 조건
선택 태그 조건: 범용 / 선택 무기                 [검색]
검색 상태                                              [취소]
결과 필터·정렬: 태그 / 보유 여부
세팅 카드: 장비 / 호석 / 범용·무기 태그 / 보유 여부
상세: 장식주 배치 / 발동 스킬·세트 효과 / 판정 근거
                                  [세팅 저장] [호석 보유 등록]
```
빈 상태: 조건 입력 또는 결과 없음 이유. 로딩: 백그라운드 실행 상태. 오류·취소·제한 도달: 완료 결과와 구분.

## 저장 세팅
목록 → 선택한 세팅의 장비·호석·장식주·스킬 상세. 빈 상태는 검색으로 연결. 데이터 버전 변경·참조 호석 삭제 시 유효성 안내 방식은 상세 설계 필요.

## 데이터·백업
게임 데이터 버전·준비 상태 / [전체 백업] / [복원 파일 선택] / 복원 변경 미리보기 / [취소] [적용]. 손상 또는 미지원 형식은 적용하지 않고 이유 표시.
