# 장비 세팅 검색

고정 무기와 목표 스킬 1~8개를 선택하면 방어구 다섯 부위, 호석, 장식주 배치를 검색한다. 일반 스킬과 세트·그룹 효과를 목표로 지정할 수 있다. 전체 커뮤니티 규칙 호석 / 보유 호석만 / 호석 없음 모드를 지원한다. 보유 모드는 입력된 보유 데이터를 사용하며 게임 생성 가능성을 재보증하지 않는다.

## 데이터 근거

- 한국어 장비 데이터: [MHDB API](https://wilds.mhdb.io/ko/armor), [API 문서](https://docs.wilds.mhdb.io/), [데이터 프로젝트](https://github.com/LartTyler/mhdb-wilds).
- 스냅샷의 API 반영 버전: **2026-04-15T01:28:18+00:00**. 이는 API의 캐시 갱신 확인용 버전이며 Capcom 게임 버전이 아니다. 최신 게임과의 일치는 미확인이다.
- 스킬 179개, 방어구 714개, 고정 무기 1,104개, 장식주 361개. 파생 정보가 없는 무기 84개는 변동 강화 조건을 검증하지 못해 제외했다.
- `scripts/export_equipment_snapshot.py`가 한국어 이름·레벨·슬롯·최대 방어력·세트 문턱을 정규화한다. 전후 API 버전이 같아야 내보내며 원본 응답 SHA256과 URL을 함께 저장한다. 원본 코드·이미지·설명 문구는 복제하지 않았다.
- 호석 규칙 근거와 공식 검증 한계는 [TALISMAN-RULE-AUDIT.md](TALISMAN-RULE-AUDIT.md) 참조. 장비 데이터에 없는 스킬(예: 가드 성능 Up) 또는 최대 레벨을 넘는 호석 후보는 제외한다.

## 검색과 검증

목표 기여도, 종류별 슬롯 수·크기, 방어력에서 다른 장비보다 불리한 장비를 제거하여 대표 후보를 구성한다. 같은 목표·슬롯 구성을 가진 호석을 합치고, 같은 구성의 보유 호석을 우선 대표로 선택한다. 목표에 포함되지 않은 스킬이나 외형이 다른 모든 장비를 나열하지 않는다.

방어구 조합을 탐색하고 부족한 목표는 장식주 재귀 검색으로 채운다. 복합 장식주의 모든 스킬을 함께 더하며 무기/방어구 슬롯과 크기를 별도로 지킨다. 세트 효과는 각 부위의 소속을 한 번씩 세어 필요 부위 수에 따라 발동한다. 출력 전 실제 장식주 위치와 목표 충족을 다시 확인한다.

최대 20개 대표 결과, 20초 또는 200,000회 탐색 제한에서 중단한다. 제한에 도달하면 부분 결과라고 표시한다. 결과 0개도 중단 상태에서는 불가능 판정이 아니다. 워커를 종료하여 취소하고, 조건·보유 데이터 변경이나 화면 닫기 시 이전 작업을 무효화한다.

## 현재 범위

장식주는 수량 무제한, 방어력은 최대 강화 기준이다. 무기 공격력 최적화, 변동 강화 무기, 장식주 보유 수량, 제작 가능 여부, 속성·내성 제약, 일반 제작 호석 전체 목록, 세팅 저장은 미구현이다. 세팅 검색이 공식 게임 전체 경우를 완전히 검증했다는 뜻은 아니다. Windows 실기기 검증은 별도 필요하다.

단위 테스트는 복합 장식주, 슬롯 종류·크기·재사용 금지, 세트 문턱, 최소 방어력, 보유 호석, 후보 축소와 제한 상태, 스냅샷 참조를 확인한다. 실제 Chromium에서 전체 규칙/호석 없음 검색, 취소, 조건 변경, 키보드 초점 복귀, 320·768·1440px 화면을 확인했다.
