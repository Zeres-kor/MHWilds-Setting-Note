# 화면 미리보기

- [데스크톱](inventory-desktop.png)
- [모바일](inventory-mobile.png)

스크린샷은 UI 확인을 위해 브라우저에서 임시로 입력한 예시 호석 1개로 촬영했다. 실제 보유 데이터나 게임 내 생성 가능 여부를 뜻하지 않는다. 화면은 `prototype/index.html`에서 직접 사용할 수 있다.

2026-10-05: 사용자 제공 공식 매뉴얼 HTML의 CSS를 참고한 어두운 올리브·금색 테마로 갱신했다. 원본 이미지 폴더는 제공되지 않았으며 CSS·자체 SVG로 구현했다.

- [호석 후보 검색 데스크톱](candidate-search-desktop.png)
- [호석 후보 검색 모바일](candidate-search-mobile.png)

후보 검색 데스크톱은 입력한 예시 호석·예시 평가 기준으로 조회한 결과이며, 모바일은 취소 상태다. 개인 게임 추출 데이터를 사용한 화면이 아니다.
