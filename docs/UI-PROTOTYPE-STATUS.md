# 보유 호석 화면 초안 상태

prototype/index.html과 style.css, app.js에 로컬 실행 초안을 작성했다. 전체 창 너비를 활용하는 표와 필터·정렬·선택 작업 영역, 모달 입력, 브라우저 저장, JSON 백업·복원을 연결했다. 사용자 입력 표시에는 textContent를 사용한다.

JS 구문 검사를 통과했다. 브라우저 검증은 실행하지 못했다: Playwright 기본 브라우저가 없으며 시스템 Chromium은 환경의 socket 권한 제한으로 실행 단계에서 종료됐다. 실제 렌더링·키보드·반응형·저장 흐름 검증은 미완료다.

자동 태그 판정, 엑셀 기준 업로드, 게임 데이터 기반 검증, 표 일괄 입력, 기존 TXT 가져오기, 세팅 검색은 아직 연결하지 않았다. 평가 필터의 분류값은 연결 전까지 미분류이며 평가 정렬은 최근 등록순을 사용한다.
