# 보유 호석 화면 초안 상태

`prototype/`은 Windows Edge/Chrome에서 로컬 실행하는 HTML/CSS/JS 화면 초안이다. 보유 호석 입력·수정·삭제, 표 붙여넣기·기존 TXT 일괄 가져오기, 검색·필터·정렬, 수동 태그 일괄 작업, 브라우저 저장, JSON 백업·복원이 연결돼 있다. 가져오기는 12열 기본 형식과 선택 메모가 있는 13열을 읽고, 행별 오류와 기존/입력 중복을 미리 보여준다. 오류 행이 있으면 적용하지 않는다. 중복이나 제공된 스킬 표에 없는 이름은 기본 선택에서 제외하고 사용자가 확인할 수 있다.

현재 화면은 이전 네이버페이 방향으로 구현한 밝은 카드형 구성이다. 2026-10-05 사용자 요청으로 향후 기준은 와일즈 공식 사이트로 변경했으며, 화면 개편은 공식 페이지 확인 후 진행한다. 새 기준과 진행 상태는 `docs/UI-DESIGN-GUIDE.md`를 따른다. 보유·표시·활성 기준 수를 요약하고 주요 입력 행동을 초록색으로 표시한다. 참고 서비스의 로고·화면 이미지는 사용하지 않는다.

태그 기준 `.xlsx` 파일의 `태그기준` 시트를 읽어 헤더·스킬명·슬롯·우선순위·수식 셀을 검증한다. 전체 교체 또는 기준 ID 병합을 선택하고 추가·변경·삭제 및 보유 호석의 태그 변동 수를 확인한 뒤 적용한다. 공통과 선택 무기의 자동 평가를 각각 계산하며, 필터·정렬과 상세 근거에 반영한다. 기준과 보유 호석을 하나의 localStorage 값으로 저장해 적용 도중 부분 상태가 남지 않도록 한다. 새 JSON 백업은 둘 다 포함하며 이전 형식의 호석 백업도 읽는다.

클라우드 Chromium에서 기준 엑셀 업로드·미리보기·적용, 공통/무기별 판정, 필터, 재방문 후 저장 유지, 호석 수정 후 재판정, 수식 셀 업로드 거부와 기존 기준 보존, JSON 백업·복원을 검증했다. 일괄 가져오기는 표 붙여넣기, TXT 읽기, 중복 선택, 오류 차단, 다른 탭 변경 감지, 키보드 초점 복귀, 320/768/1024/1440px 배치를 확인했다. Node 단위 테스트 14개가 통과했다. Windows 실기기 검증은 아직 하지 않았다.

게임 내 호석 생성 가능 여부, 장비 세팅 검색과 Windows 배포는 아직 구현되지 않았다. 스킬명 목록은 제공된 원본 호석 표에서 가져왔으며 실제 게임 데이터의 완전성을 검증한 목록은 아니다.

게임 추출 TXT(사용자 첨부 555행)를 파일 선택과 드롭으로 읽고, 오류·미확인 스킬 0개와 동일 구성 1개를 확인했다. 중복 포함 555개 저장·새로고침 유지, 엑셀 드롭·적용, JSON 드롭·복원, 잘못된 확장자·여러 파일·크기 초과·잘못된 행 거부를 Chromium에서 확인했다. 느린 파일 읽기 도중 새 파일 선택·텍스트 수정·대화상자 닫기를 했을 때 이전 읽기가 덮어쓰지 않는 것도 확인했다. 개인 추출 파일은 저장소에 포함하지 않는다.
