# 보유 호석 화면 초안 상태

`prototype/`은 Windows Edge/Chrome에서 로컬 실행하는 HTML/CSS/JS 화면 초안이다. 보유 호석 입력·수정·삭제, 검색·필터·정렬, 수동 태그 일괄 작업, 브라우저 저장, JSON 백업·복원이 연결돼 있다.

태그 기준 `.xlsx` 파일의 `태그기준` 시트를 읽어 헤더·스킬명·슬롯·우선순위·수식 셀을 검증한다. 전체 교체 또는 기준 ID 병합을 선택하고 추가·변경·삭제 및 보유 호석의 태그 변동 수를 확인한 뒤 적용한다. 공통과 선택 무기의 자동 평가를 각각 계산하며, 필터·정렬과 상세 근거에 반영한다. 기준과 보유 호석을 하나의 localStorage 값으로 저장해 적용 도중 부분 상태가 남지 않도록 한다. 새 JSON 백업은 둘 다 포함하며 이전 형식의 호석 백업도 읽는다.

2026-10-02 클라우드 Chromium에서 기준 엑셀 업로드·미리보기·적용, 공통/무기별 판정, 필터, 재방문 후 저장 유지, 호석 수정 후 재판정, 수식 셀 업로드 거부와 기존 기준 보존, JSON 백업·복원을 검증했다. Node 판정기 단위 테스트 5개가 통과했다. Windows 실기기 검증은 아직 하지 않았다.

게임 내 호석 생성 가능 여부, 표 일괄 입력, 기존 TXT 가져오기, 장비 세팅 검색과 Windows 배포는 아직 구현되지 않았다. 스킬명 목록은 제공된 원본 호석 표에서 가져왔으며 실제 게임 데이터의 완전성을 검증한 목록은 아니다.
