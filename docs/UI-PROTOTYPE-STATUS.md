# 보유 호석 화면 초안 상태

`prototype/`은 GitHub Pages에서 제공하는 HTML/CSS/JS 웹 앱이다. 보유 호석 입력·수정·삭제, 표 붙여넣기·기존 TXT 일괄 가져오기, 검색·필터·정렬, 수동 태그 일괄 작업, 브라우저 저장, JSON 백업·복원이 연결돼 있다. 가져오기는 12열 기본 형식과 선택 메모가 있는 13열을 읽고, 행별 오류와 기존/입력 중복을 미리 보여준다. 오류 행이 있으면 적용하지 않는다. 중복이나 제공된 스킬 표에 없는 이름은 기본 선택에서 제외하고 사용자가 확인할 수 있다.

화면은 사용자 제공 와일즈 공식 매뉴얼 HTML의 CSS를 참고한 어두운 배경·올리브 메뉴·금색 강조·명조 제목 구성이다. 데스크톱은 왼쪽 메뉴, 좁은 화면은 가로 메뉴를 사용한다. 보유·표시·활성 기준 수와 기존 관리 기능을 유지하며 자체 CSS·SVG로 장식한다. 근거와 앞으로의 원칙은 `docs/UI-DESIGN-GUIDE.md`를 따른다.

태그 기준 `.xlsx` 파일의 `태그기준` 시트를 읽어 헤더·스킬명·슬롯·우선순위·수식 셀을 검증한다. 전체 교체 또는 기준 ID 병합을 선택하고 추가·변경·삭제 및 보유 호석의 태그 변동 수를 확인한 뒤 적용한다. 공통과 선택 무기의 자동 평가를 각각 계산하며, 필터·정렬과 상세 근거에 반영한다. 기준과 보유 호석을 하나의 localStorage 값으로 저장해 적용 도중 부분 상태가 남지 않도록 한다. 새 JSON 백업은 둘 다 포함하며 이전 형식의 호석 백업도 읽는다.

클라우드 Chromium에서 기준 엑셀 업로드·미리보기·적용, 공통/무기별 판정, 필터, 재방문 후 저장 유지, 호석 수정 후 재판정, 수식 셀 업로드 거부와 기존 기준 보존, JSON 백업·복원을 검증했다. 일괄 가져오기는 표 붙여넣기, TXT 읽기, 중복 선택, 오류 차단, 다른 탭 변경 감지, 키보드 초점 복귀, 320/768/1024/1440px 배치를 확인했다. Node 단위 테스트는 후보 검색을 포함해 23개가 통과했다. Windows 실기기 검증은 아직 하지 않았다.

게임 내 호석 생성 가능 여부, 장비 세팅 검색과 Windows 배포는 아직 구현되지 않았다. 스킬명 목록은 제공된 원본 호석 표에서 가져왔으며 실제 게임 데이터의 완전성을 검증한 목록은 아니다.

게임 추출 TXT(사용자 첨부 555행)를 파일 선택과 드롭으로 읽고, 오류·미확인 스킬 0개와 동일 구성 1개를 확인했다. 중복 포함 555개 저장·새로고침 유지, 엑셀 드롭·적용, JSON 드롭·복원, 잘못된 확장자·여러 파일·크기 초과·잘못된 행 거부를 Chromium에서 확인했다. 느린 파일 읽기 도중 새 파일 선택·텍스트 수정·대화상자 닫기를 했을 때 이전 읽기가 덮어쓰지 않는 것도 확인했다. 개인 추출 파일은 저장소에 포함하지 않는다.

메뉴의 규칙 기준 호석 후보 검색을 구현했다. 스킬·레벨·레어도·슬롯·태그 조건, 공통/무기 평가·보유 수량, 취소·부분 검색 제한을 지원한다. 실제 워커와 빈 결과·입력 오류·상태 변경 무효화를 Chromium에서 확인했다. 게임 전체 후보 및 장비 세팅 검색은 아니며, 데이터 누락과 검증 상태는 `CANDIDATE-SEARCH.md`를 따른다.

커뮤니티 출처로 가드 강화 그룹 배정을 보완하고, 같은 스킬명 중복 배정·합산 제외의 근거를 기록했다. 보완 규칙과 실제 추출 555행의 구성이 모두 일치했다. 게임 전체 생성 가능성 및 실제 레어도 검증은 아니며 `TALISMAN-RULE-AUDIT.md`를 참고한다.

## 2026-10-05 장비 세팅 검색 갱신

세팅 검색 메뉴를 연결했다. 고정 무기·목표 스킬/세트 효과·호석 범위·방어구 등급·방어력 입력, 워커 검색/취소, 장비와 장식주 위치 및 발동 효과 결과를 제공한다. 데이터 기준일과 부분 결과를 표시한다. 범위와 미구현 사항은 BUILD-SEARCH.md 참조.

## 메뉴 페이지 전환

주 메뉴는 본문 페이지로 전환한다. `#inventory`, `#rules`, `#candidates`, `#build`를 직접 열거나 새로고침할 수 있다. 브라우저 뒤로/앞으로 가기를 지원하고 페이지를 떠나면 실행 중인 검색·파일 읽기를 취소한다. 기준 적용 후에는 태그 기준 페이지에서 적용 결과를 표시한다. 개별 호석 입력·일괄 태그·가져오기는 작업 팝업을 유지한다.

## 저장 세팅·비교 갱신

검색 결과 저장, #saved 페이지의 이름·메모 편집/삭제, 최대 3개 비교와 차이 강조, 스냅샷 백업·복원을 연결했다. 상세 범위와 이전 백업 동작은 SAVED-BUILDS.md 참조.

## 무기 선택 범위

세팅 검색의 무기는 아티어 기본 구성 / 제작 최종 강화로 묶어 표시한다. 제작 중간 단계는 제외한다. 아티어 선택 시 복원 보너스·추가 부여 효과가 미반영임을 안내한다. 기존 저장 세팅은 변경하지 않는다.

## 목표 스킬 분류와 거극 아티어 설정

목표마다 스킬 분류와 이름·효과명 검색을 지원한다. 거극 아티어에 시리즈·그룹 스킬을 지정하면 각 1부위로 검색과 발동 효과를 계산하고 저장·비교에도 표시한다. 실제 무기 부여 가능성·복원 수치 검증은 미구현이다. 상세 BUILD-SEARCH.md 참조.

## 분류별 전체 스킬 메뉴

목표 행 추가 대신 전체 스킬을 분류별 목록으로 표시하고 각 스킬 옆에서 레벨·효과를 선택한다. 검색·분류 변경에도 목표 선택은 유지된다. 선택 요약과 개별·전체 해제를 제공한다. 목표 8개 제한은 UI·검색·저장·복원에서 제거했다.

## 스킬 메뉴 밀도·표 제목 고정

일반 레벨 선택 폭을 줄이고 이름 옆에 배치했다. 무기 전용 15개는 자동 목표에 유지하고 수동 메뉴에서는 숨긴다. 보유 표는 표 영역 내부 스크롤에 제목 행이 고정되며 키보드 초점·가로 스크롤도 지원한다.
