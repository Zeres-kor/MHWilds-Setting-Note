## 반영 범위

사용자 원본 엑셀은 수정하지 않았다. 출처가 있는 보완 규칙을 `inputs/talisman-rule-overrides.json`으로 관리하고, 배포용 JSON을 재생성할 때 함께 적용한다. 현재 범위는 **엑셀 + 커뮤니티 규칙**이며 공식 게임 명세나 모든 게임 버전을 검증한 데이터가 아니다.

## 동일 스킬 중복과 합산

커뮤니티 자료 두 곳에서 **스킬명 기준으로 이미 배정된 스킬을 제외**하는 처리를 확인했다.

- 위 생성기의 `skill_assign`: 모든 선택 위치에서 스킬 이름을 `seen`으로 관리해 중복을 제외한다. 서로 다른 그룹·레벨인 경우도 이름이 같으면 제외한다.
- [확률 계산기의 amuletProb.js](https://github.com/ni-null/MHWilds-Charm-Odds-Calculator/blob/90e1d852c0fa20ce3e38f36dbc679c0d105fe6dd/src/lib/amuletProb.js): `usedBaseNamesGlobal`에 있는 이름을 후속 그룹에서 제외한다. 이 도구의 [주의 문구](https://github.com/ni-null/MHWilds-Charm-Odds-Calculator/blob/90e1d852c0fa20ce3e38f36dbc679c0d105fe6dd/src/i18n/locales/en-US.json)도 실제 게임 동작과 다를 수 있음을 밝힌다.

따라서 현재 검색의 중복 제외 동작을 유지하고, 근거 상태를 단순 미확정 가정에서 **커뮤니티 자료로 교차 확인한 규칙**으로 갱신했다. 레벨을 합산하지 않는다. 예를 들어 공격 Lv.1과 공격 Lv.2를 두 위치에 배정해 공격 Lv.3으로 만들지 않는다. 입력·가져오기에서도 기존 동일 스킬 중복 거부를 유지한다. 공식 규칙으로 확인한 것은 아니다.

## 추출 파일 대조

제공된 게임 추출 555행을 스킬의 정확한 레벨, 위치를 바꾼 그룹 배정, 무기·방어구 슬롯의 정확 일치로 비교했다.

| 대조 | 원본 엑셀 | 가드 강화 보완 후 |
|---|---:|---:|
| 규칙과 일치 | 536 | 555 |
| 스킬·레벨 누락 | 19 | 0 |
| 그룹 조합 불일치 | 0 | 0 |
| 슬롯 불일치 | 0 | 0 |

555행에서 동일 스킬 중복을 발견하지 않았다. 표본에서 중복이 없다는 사실만으로 게임 전체의 중복 금지를 증명하지는 않는다. TXT에 레어도 정보가 없으므로 해당 호석의 실제 레어도까지 확인한 것은 아니다. 한 구성에 맞는 레시피·레어도는 복수일 수 있다. 개인 추출 파일과 개별 구성은 저장소·배포에 포함하지 않았다.

`node scripts/audit_talisman_export.cjs /path/to/Exported_Talismans.txt`로 같은 대조를 다시 실행할 수 있다. 개인 구성은 출력하지 않고 합계만 출력한다. `TalismanCandidates.matchRecord`는 규칙 대조 함수이며 게임 유효성 판정기가 아니다.
