# 사용자 흐름

## 첫 실행
보유 호석 화면 → 로컬 데이터 준비 상태 확인 → 데이터가 있으면 등록/가져오기 → 없다면 준비 상태·오류 안내. 태그 기준이 없어도 호석 관리를 시작할 수 있으며 자동 태그는 미분류다.

## 기준 등록·갱신
태그 기준 메뉴 → 엑셀 선택 → 검증 → 오류가 있으면 행·열 안내 후 재업로드 → 정상 파일은 추가/수정/삭제 기준과 태그 영향 미리보기 → 적용 → 관련 호석 재분류 → 결과 확인. 취소하면 기존 상태를 유지한다. 기준 교체/병합 방식은 별도 확정한다.

## 호석 입력
보유 호석 → 개별 또는 일괄 입력 → 규칙 검증 → 오류 수정 → 중복 확인 → 저장 → 공통·무기별 태그 확인 → 연속 입력 또는 목록 복귀.

## 보유 목록 활용
무기 선택 → 범용 태그와 무기 태그 확인 → 스킬·슬롯·태그 복합 필터 → 정렬 → 호석 상세와 판정 근거 → 수정 또는 여러 항목 선택 후 일괄 작업. 결과가 없으면 조건을 해제하거나 새 호석을 등록한다.

## 전체 가능 호석 세팅 검색
세팅 검색 → 무기 선택 → 전체 가능 호석 모드 → 목표 스킬·장비 조건 → 선택적으로 태그 제한 → 검색 → 실행 상태/취소 → 결과 → 태그·보유 여부로 비교 → 세팅 저장 또는 호석 보유 등록 미리보기. 결과 없음과 실행 실패·취소·탐색 제한은 구분한다.

## 보유 호석 세팅 검색
보유 모드 선택 → 호석이 없으면 등록 안내 → 있으면 검색 → 결과 비교·저장. 미보유 호석이 들어간 결과는 이 모드에서 나오지 않아야 한다.

## 재방문·복구
앱 재실행 → 호석·기준·저장 세팅 복원 → 목록 또는 저장 세팅 이용. 백업 복원은 파일 검증 → 변경 미리보기 → 적용 → 호석·태그·세팅 확인 순서로 진행한다.
